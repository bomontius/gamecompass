# Credits / Katkılar

## Türkçe

Oyun Pusulası / GameCompass, kişisel oyun keşfini yerel ve açıklanabilir tutmak amacıyla hazırlanmıştır.

- Ürün fikri, kategori modeli ve profil yaklaşımı: Bomontius.
- Uygulama arayüzü ve yerel veri akışı: Oyun Pusulası projesi.
- Masaüstü paketleme: Electron ve electron-builder.
- Yerel servis ve veri işleme: Python standart kütüphanesi.
- Oyun mağazası künyeleri ve kütüphane aktarımı: Steam Web API ve herkese açık Steam mağaza verileri.
- Pusula ikonu: Bu proje için hazırlanmış özgün SVG/ICO çalışması.

Steam ve Steam logosu Valve Corporation'ın ticari markalarıdır. Bu proje Valve tarafından desteklenmez veya Valve ile bağlantılı değildir.

## English

Oyun Pusulası / GameCompass is built to make personal game discovery local, transparent, and preference-driven.

- Product concept, category model, and profile approach: Bomontius.
- Application UI and local data flow: the Oyun Pusulası project.
- Desktop packaging: Electron and electron-builder.
- Local service and data processing: the Python standard library.
- Store metadata and optional library import: Steam Web API and public Steam store data.
- Compass icon: an original SVG/ICO asset made for this project.
