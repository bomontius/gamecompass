# Game Compass v1.0.0 — Complete feature overview

Game Compass is a local-first Windows desktop application for personal game discovery. The release is presented as a complete product overview.

## Türkçe

### Profil ve kişiselleştirme

- İlk profil için kapatılamayan beş adımlı oluşturma akışı.
- Zorunlu profil adı.
- Görmek istenenler ve önerilmeyecek oyun tipleri için 10–1000 karakterlik alanlar.
- En az bir ana kategori ve bir alt tür seçimi.
- Serbest metin, kategori, alt tür, beğenme, beğenmeme ve oyun tipi dışlama sinyalleri.
- Birden fazla profil, profil geçişi, profil sıfırlama ve profil silme.
- Türkçe ve English dil seçimi.
- Altı tema, altı yazı tipi ve küçük/normal/büyük yazı boyutu.
- Üç oyun atmosferi arka planı, hafif canlı/parallax hareket ve azaltılmış hareket desteği.
- Tema ve yazı tipi seçimlerinde canlı önizleme.

### Keşif ve öneriler

- Koloni yönetimi ve RimWorld benzeri base building.
- Manor Lords ve Ostriv çizgisinde şehir kurma.
- Gerçek tarihe odaklanan grand strategy.
- Gerçekçi shooter; sihirli veya fantastik rekabetçi shooter türleri tercih dışı sinyal olarak desteklenir.
- Football Manager tarzı menajerlik, ofis yönetimi, yönetim simülasyonu ve tycoon oyunları.
- Profil uyumlu güçlü öneriler ve ayrı alt liste.
- Yeni gelenler ve yakında çıkacaklar görünümleri.
- Her açılışta Hoş geldin ekranı.
- Yerel tarihe ve aktif profile göre günlük öneri.
- Kategori bazlı, açılır-kapanır listeler.
- Ana kategori ve alt türlerde çoklu filtreleme.
- Arama, uyum/puan/çıkış/oynama saati sıralaması.

### Oyun künyeleri

- Steam puanı, oy sayısı ve olumlu yüzdesi.
- Çıkış tarihi, kısa özet ve kategori/tür etiketleri.
- Steam mağaza sayfasını varsayılan tarayıcıda açma.
- İstendiğinde Steam görselleri ve fragmanını yükleme.
- New ve New on list etiketleri.

### Kütüphane ve yerel kararlar

- Steam Web API ile isteğe bağlı kütüphane aktarımı.
- JSON, CSV, TSV ve XML kütüphane aktarımı.
- Steam oyun adı arayarak tek tek oyun ekleme.
- Kütüphanede oynama saatlerini gösterme; oynama saatlerini öneri profilinin yerine kullanmama.
- Kaydetme, kişisel not, karşılaştırma, planlama ve yaklaşan çıkış takibi.
- Kişisel raflar ve dışlananlar görünümü.
- JSON profil yedeği alma ve geri yükleme.
- İlk açılış sihirbazından yedek klasörü veya JSON içe aktarma.

### Rehber, güncelleme ve dağıtım

- Sekmeleri ve kontrolleri renkli odak çerçevesiyle gösteren aşamalı rehber.
- Bu adımı atla ve Rehberi atla seçenekleri.
- İlk profil tamamlanınca otomatik rehber; rehber bitince Hoş geldin ekranına dönüş.
- Cuma 13:00–20:00 aralığında haftalık katalog taraması.
- Manuel güncelleme düğmesi.
- GitHub release kontrolü ve yeni sürüm bildirimi.
- GitHub repo bağlantısı ve Made by Bomontius imzası.
- Seçilebilir Windows kurulum klasörü.
- Masaüstü ve Başlat menüsü kısayolları.
- Windows kaldırma kaydı.
- Uygulama dosyalarından ayrı, Belgeler\Game Compass\runtime\data altında yerel kullanıcı verisi.

## English

### Profiles and personalization

- A required five-step first-profile flow.
- Required profile name.
- 10–1000 character fields for games to show and game types to avoid.
- At least one main category and one subgenre.
- Written preferences, category, subgenre, like, dislike and game-type exclusion signals.
- Multiple profiles, profile switching, reset and delete.
- Turkish and English language selection.
- Six themes, six fonts, and small/normal/large font sizes.
- Three game-atmosphere backgrounds, subtle live/parallax motion and reduced-motion support.
- Live previews for theme and font choices.

### Discovery and recommendations

- Colony management and RimWorld-like base building.
- City building in the style of Manor Lords and Ostriv.
- Grand strategy focused on real history.
- Realistic shooters, with magical or fantasy competitive shooters supported as exclusion signals.
- Football Manager-style management, office simulation, management simulation and tycoon games.
- Strong profile matches and a separate lower lane.
- New arrivals and upcoming releases.
- A Welcome screen on every launch.
- A daily recommendation based on local date and active profile.
- Categorized collapsible lists.
- Multi-select main-category and subgenre filters.
- Search and fit/rating/release/playtime sorting.

### Game dossiers

- Steam rating, review count and positive percentage.
- Release date, short summary, and category/subgenre tags.
- Steam store pages opened in the system default browser.
- On-demand Steam screenshots and trailer loading.
- New and New on list badges.

### Library and local decisions

- Optional Steam Web API library import.
- JSON, CSV, TSV and XML library import.
- Individual game lookup through Steam search.
- Playtime shown in the library without replacing the taste profile.
- Save, notes, comparison, planning and upcoming-release follows.
- Personal shelves and excluded view.
- JSON profile backup and restore.
- First-launch import from a backup folder or JSON file.

### Guide, updates and distribution

- A step-by-step guide with colored focus frames around tabs and controls.
- Skip this step and Skip tutorial options.
- Automatic guide after first profile creation, returning to Welcome when it ends.
- Weekly catalog scan on Fridays between 13:00 and 20:00.
- Manual update button.
- GitHub release checking and update notification.
- GitHub repository link and Made by Bomontius credit.
- Selectable Windows installation folder.
- Desktop and Start Menu shortcuts.
- Windows uninstall registration.
- Local user data kept separately from application files in Documents\Game Compass\runtime\data.
